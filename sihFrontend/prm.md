# Jagruk Swadesh — Frontend PRM

## 1. Project Overview

Build the public-facing frontend website for **Team Jagruk Swadesh**, an AI-powered intelligent assistant platform for Indian Standards and BIS services.

The frontend should provide a premium, modern and trustworthy introduction to Jagruk Swadesh and guide users toward exploring BIS-related information or accessing the separately developed chatbot.

### Frontend Scope

This PRM covers only the frontend experience before the chatbot.

### Required Pages

1. Home / Landing Page
2. Explore
3. About Us
4. Login
5. Sign Up
6. Privacy Policy

### Shared Components

- Navbar
- Footer
- Responsive mobile navigation
- Reusable buttons
- Reusable liquid-glass cards
- Page transitions
- Hover interactions
- Chatbot entry CTA only

### Important

The chatbot is already being developed separately by another team member.

**DO NOT design or implement the chatbot UI, chat messages, chat history, chatbot logic, AI response interface, RAG interface or source panel.**

Only provide a clear integration point such as:

**"Ask Jagruk Swadesh"**

The existing chatbot can later be connected to this CTA.

---

# 2. Product Context

Jagruk Swadesh is an AI-powered platform designed to make information related to the Bureau of Indian Standards (BIS) easier to discover and understand.

The platform focuses on information such as:

- Indian Standards
- BIS Certification
- Testing and Laboratories
- Hallmarking
- Consumer-related BIS information

The core idea is:

**Scattered BIS information → intelligent understanding → simpler user experience**

The website should communicate that Jagruk Swadesh is more than a generic chatbot. It is a trustworthy Indian platform designed to make BIS-related information easier to access.

---

# 3. Overall Design Direction

## Advanced Liquid Glass

The website must use a **premium crystal-clear liquid glass UI**.

This is NOT traditional glassmorphism.

The liquid glass should feel:

- Crystal clear
- Fluid
- Refined
- Layered
- Transparent
- Physically realistic
- Premium
- Lightweight
- Modern

Use:

- Subtle transparency
- Controlled backdrop blur
- Soft refraction
- Fine borders
- Delicate highlights
- Natural shadows
- Layered depth
- Smooth surface transitions
- Subtle reflections

The interface should look like high-quality transparent liquid surfaces floating naturally over the background.

---

# 4. Things to Avoid

Absolutely avoid:

- Rainbow gradients
- Neon effects
- Cyberpunk aesthetics
- Excessive glowing borders
- Bright purple/blue AI gradients
- Generic AI SaaS appearance
- Excessive blur
- Heavy frosted glass
- Generic glassmorphism cards
- Too many floating blobs
- Excessive rounded pill components
- Cartoon illustrations
- Overly colorful cards
- Fake statistics
- Fake testimonials
- Fake user counts
- Unnecessary dashboards
- Excessive animations

The website must feel **professional and trustworthy**, not flashy.

---

# 5. Background

Use the supplied **green atmospheric nature background** as the primary visual background.

The background should remain visible throughout the website where appropriate.

The background has:

- Deep natural green
- Soft atmospheric light
- Mist
- Organic flowing forms
- Natural depth
- Calm visual character

Do not replace it with a generic gradient.

Do not completely hide it behind opaque UI sections.

The interface should appear to naturally float over this environment.

Use dark translucent overlays only when necessary for readability.

---

# 6. Indian Visual Identity

The design should feel distinctly Indian but subtle and sophisticated.

Use:

- Natural green
- Warm ivory/white
- Muted saffron/amber accents
- Minimal Indian-inspired visual language

Do NOT overuse:

- Indian flags
- Tricolor gradients
- Ashoka Chakra
- Patriotic graphics
- Decorative cultural clichés

Indian identity should come from the overall color harmony, typography, content and visual restraint.

# 22. Animation Rules

Animations should be purposeful.

Recommended:

- 180–300ms for small UI interactions
- 300–600ms for larger transitions
- Slow background movement if required

Use:

- Smooth page transitions
- Scroll reveal
- Hover transitions
- Button feedback
- Mobile menu transitions

Do not animate every component.

Avoid flashy motion.

The overall animation style should feel:

**Elegant + smooth + premium + calm**

---

# 23. Responsive Design

The website must work properly on:

- Desktop
- Laptop
- Tablet
- Mobile

Mobile should not simply be a compressed desktop layout.

### Mobile requirements

- Responsive navbar
- Hamburger menu
- Stacked hero content
- Full-width CTA buttons where appropriate
- Single-column cards
- Stacked footer
- Touch-friendly controls
- Proper spacing

Maintain the liquid-glass aesthetic on smaller screens without sacrificing performance or readability.

---

# 24. Accessibility

Prioritize:

- Strong text contrast
- Readable typography
- Keyboard navigation
- Visible focus states
- Accessible buttons
- Proper semantic HTML
- Touch-friendly controls
- Reduced-motion support

The visual design must never compromise usability.
